# MEI-Princeton: hearing real spaces

HackPrinceton Fall '26 project for the CoStar track. It simulates how sound behaves inside real
Houston and Los Angeles properties, using Matterport room geometry, CoStar property data and Vexcel
aerial imagery.

- Project pitch: [docs/project/proposal.md](docs/project/proposal.md)
- Folder map and where to find things: [AGENTS.md](AGENTS.md)
- CoStar data kit: [costar-kit/index.md](costar-kit/index.md)

## Setup

Copy your keys into `.env` (it is git-ignored). Variables: `MATTERPORT_API_KEY`, `MATTERPORT_API_TOKEN`,
`MATTERPORT_SDK_KEY`, `VEXCEL_API_KEY`.

## Key rules (summary)

- Public GitHub repo created between Nov 13 and Nov 15, 2026. All hacking happens within the 36-hour window.
- Devpost deadline: **8:00 AM Sunday, Nov 15** (hard).
- Live demo of 2 minutes or less during judging (9:30 AM–2:30 PM Sunday). A 2-minute video is optional but recommended.
- At most 4 team members. Add Discord usernames to the submission and select the prize tracks.
- CoStar track judging weights are in [../project/proposal.md](../project/proposal.md).

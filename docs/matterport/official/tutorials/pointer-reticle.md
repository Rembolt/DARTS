## Visibility Control​

You can control the visibility of the pointer reticle. See [Pointer.setVisible](/reference/pointer/)

note

The user can continue to interact with the space while the cursor is not visible.

## Custom Texture​

You can set the pointer reticle texture. See [Pointer.registerTexture](/reference/pointer/), [Pointer.editTexture](/reference/pointer/), and [Pointer.resetTexture](/reference/pointer/). You will need to register your textures prior to calling `Pointer.editTexture`.

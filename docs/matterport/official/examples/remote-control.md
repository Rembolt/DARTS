This example can be found within the [rc-app](https://github.com/matterport/showcase-sdk-examples/tree/main/packages/rc-app) in the [Showcase SDK Examples](https://github.com/matterport/showcase-sdk-examples) repository.

This example demonstrates how the Showcase Embed SDK can be used to let one user, the host, drive the experience for other users. Practical use cases based on this example include a virtual open house experience, or a virtual visit of a facility for discovery or training purposes.

To try this example:

  * The host user enters a session name and model sid

  * The client user selects an active session to join




For testing, a single user can play both roles in multiple browser windows.

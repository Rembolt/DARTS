Two variants of the same Tags-driven quiz experience. Use the buttons above the viewer to switch.

  * **Tags Quiz** (default) — the original in-space quiz, with question content embedded in Tags
  * **Tags Quiz Overlay** — an alternate take where the question UI is rendered as an HTML overlay on top of the embed



Source for the overlay variant lives in the [embed-examples](https://github.com/matterport/showcase-sdk-examples/tree/main/packages/embed-examples/examples) folder of the [Showcase SDK Examples](https://github.com/matterport/showcase-sdk-examples) repository.

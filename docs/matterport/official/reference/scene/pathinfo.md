On this page

The objects returned by the `pathIterator` implement this interface. Each descriptor and path should correlate by type. For example, a path of type [`PathType.INPUT`](/reference/scene/#enum-pathtype) would have a descriptor of type [`InputPathDescriptor`](/reference/scene/#type-inputpathdescriptor) and path of type [`InputPath`](/reference/scene/inputpath/).
